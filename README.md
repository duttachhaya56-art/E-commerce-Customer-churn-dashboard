# E-Commerce Customer Churn Analytics & Master Dashboard

A comprehensive end-to-end data analytics project focused on analyzing customer behavior, identifying churn risks, and presenting actionable business insights through an executive Power BI master dashboard.

---

## 📊 Project Overview
Customer retention is critical for e-commerce growth. This project processes raw customer data, applies predictive analytics to identify high-risk segments, and unifies fragmented metrics into a single, cohesive master dashboard to support data-driven decision-making.
